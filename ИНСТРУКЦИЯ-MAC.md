# Установка платформы на Mac

Платформа работает на любом Mac с macOS 11 (Big Sur) или новее — и на Apple Silicon (M1–M4),
и на Intel. Всё делается мышью, Терминал знать не нужно: файлы `.command` открываются
двойным щелчком, окно Терминала при этом появится само — так и должно быть.

Как пользоваться панелью, подключать 1С, маркетплейсы и сценарии — в основной
`ИНСТРУКЦИЯ.md`: там всё одинаково для Windows и Mac. Здесь — только отличия.

## 1. Что понадобится

- Mac, который будет включён постоянно (Mac mini — идеальный вариант);
- архив `Platforma-…-mac.zip`;
- учётная запись Mac с правами администратора (только для установки Python).

## 2. Установить Python (один раз)

1. Откройте в Safari **python.org → Downloads → macOS**.
2. Скачайте **Python 3.12** — строка «macOS 64-bit universal2 installer».
3. Откройте скачанный файл `.pkg` и нажимайте «Продолжить» → «Установить».
   Mac попросит пароль — введите пароль от своей учётной записи.
4. В конце откроется папка Python — её можно закрыть.

Python из Homebrew тоже подходит, если он уже стоит.

## 3. Распаковать платформу

1. Дважды щёлкните архив `Platforma-…-mac.zip` — рядом появится папка `Platforma`.
2. **Перетащите папку `Platforma` в папку пользователя** (в Finder: меню «Переход» → «Домой»,
   там папка с домиком и вашим именем).

   Не оставляйте её в «Загрузках», «Документах» или на «Рабочем столе»: оттуда macOS
   не даст запускать платформу автоматически.

## 4. Первый запуск: разрешить файл

macOS не доверяет файлам из интернета, поэтому **первый** файл нужно разрешить вручную.

1. Откройте папку `Platforma`, нажмите на `установить.command` **правой кнопкой** → «Открыть» →
   в окне предупреждения снова «Открыть».
2. Если кнопки «Открыть» в окне нет (macOS 15 Sequoia и новее): нажмите «Готово», затем
   откройте  → «Системные настройки» → «Конфиденциальность и безопасность», прокрутите вниз
   и нажмите **«Всё равно открыть»** рядом с `установить.command`, введите пароль.

Установщик сам снимет эту пометку со всех остальных файлов папки — дальше они открываются
обычным двойным щелчком.

## 5. Установка

Окно установщика покажет четыре шага. Библиотеки лежат в архиве (папка `wheels`), поэтому
интернет не нужен. В конце появится «Установка завершена» — нажмите Enter.

## 6. Запуск

Дважды щёлкните **`запустить.command`** — откроется браузер с панелью
`http://localhost:8080`. Первый вход: логин `admin`, пароль `admin`, дальше панель попросит
придумать новый пароль.

Если macOS спросит **«Разрешить приложению Python принимать входящие сетевые подключения?»** —
нажмите «Разрешить», иначе панель не откроется с других компьютеров.

С других компьютеров офиса панель открывается по адресу Mac: его видно в  →
«Системные настройки» → «Сеть» → Wi-Fi или Ethernet → «Подробнее» → IP-адрес.
Например: `http://192.168.1.25:8080`.

## 7. Чтобы платформа работала всегда

1. **Автозапуск.** Дважды щёлкните `автозапуск-включить.command`. Теперь платформа запускается
   сама после входа в систему и поднимается заново, если вдруг упадёт.
2. **Автоматический вход.**  → «Системные настройки» → «Пользователи и группы» →
   «Автоматический вход» → выберите свою учётную запись. Без этого после перезагрузки
   платформа ждёт, пока кто-нибудь войдёт в Mac.
   Если пункт недоступен — выключите FileVault («Конфиденциальность и безопасность» → FileVault):
   macOS не разрешает автоматический вход при шифровании диска.
3. **Сон.** Пока платформа работает, Mac не уснёт сам — она это запрещает. Экран при этом
   гаснет как обычно. Для ноутбука держите его на зарядке.
4. **После отключения света.** «Системные настройки» → «Энергосбережение» (на Mac mini)
   → включите «Запускать автоматически после сбоя питания».

## 8. Файлы в папке

| Файл | Что делает |
|---|---|
| `установить.command` | установка и повторная установка (данные не трогает) |
| `запустить.command` | запустить платформу и открыть панель |
| `остановить.command` | остановить платформу |
| `автозапуск-включить.command` | запускать платформу саму после входа в систему |
| `автозапуск-выключить.command` | выключить автозапуск (платформа остановится) |
| `резервная-копия.command` | сделать копию прямо сейчас (копии и так делаются каждый день) |
| `восстановить-из-копии.command` | откроет окно выбора файла копии и восстановит данные |
| `сменить-порт.command` | если порт 8080 занят другой программой |
| `сбросить-пароль-администратора.command` | вход admin/admin, если пароль забыт |

## 9. Если что-то не так

| Что видно | Что делать |
|---|---|
| «Не удаётся открыть, так как разработчик не подтверждён» | см. п. 4: правой кнопкой → «Открыть» или «Всё равно открыть» |
| Двойной щелчок открывает файл в текстовом редакторе | архив распакован не штатной «Утилитой архивов»: распакуйте его заново двойным щелчком |
| «Не найден Python 3.11 или новее» | установите Python 3.12 с python.org (п. 2) и повторите |
| Панель не открывается с других компьютеров | «Системные настройки» → «Сеть» → «Брандмауэр» → «Параметры» → для Python выберите «Разрешать входящие подключения» |
| После перезагрузки панель не открывается | проверьте автозапуск (п. 7.1) и автоматический вход (п. 7.2) |
| Что-то другое | откройте в панели «Тестирование» → «Проверить всё». Журнал работы — `logs/app.log` в папке платформы: его и присылайте разработчику |

## 10. Перенос с Windows на Mac и обратно

Резервная копия одна и та же на обеих системах. На старом сервере — «Настройки» →
«Резервные копии» → «Сделать копию» → «Скачать». На Mac — установите платформу (п. 2–5),
положите файл копии в папку `backups` и запустите `восстановить-из-копии.command`.
Все подключения, сотрудники и сценарии переедут вместе с ключом шифрования.
